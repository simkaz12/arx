The codex gate ran four rounds. Round 1's credential-in-trace finding was overruled: the brief's own clamp bullet accepts a hand writing under `/hand/out` and `/hand/home`, and the Owner items section named that exact risk for a veto the owner did not take. Round 4 raised nothing new and approved. Every fix carries its own unit test in `main.rs`'s test module; none touches a file this brief or the amendment named as unedited.
