# L2-10a — the native loop: multi-turn, the window's op-set, a live kill

Cut from L2-10 on 2026-09-04 by main under the owner's overnight clearance: the loop itself is one session; the error classes, the gauge and the second adapter each need it first.

## Deliverable

The Goose lift's loop on top of L1-10's one turn. `run_one_turn` becomes a loop: a `ToolUse` termination executes the calls and calls `complete` again with the tool results appended, until `EndTurn`, `MaxTokens` or `Refusal` ends the brief, under a step cap from the agent definition so a hand cannot spin. The window is a type with two operations, `append` and `rewind` (cut the tail to a length and hand the cut back to the caller), and no splice; the loop only ever appends. The kill path carried from L1-10 becomes live: a stalled request made of keep-alive lines is interrupted by `Control::Kill` within a bounded time, by the mechanism the brief picks among the three the parent named (a cancel flag polled between reads, a short read timeout, an async client on a private runtime behind the synchronous trait), with L1-10's `Provider` trait unchanged. Built for the hand role; the main seat stays fog.

## Done when

A scripted provider yielding `ToolUse` then `EndTurn` makes exactly two `complete` calls and the second request carries the first turn's assistant message and the tool result in order; a scripted provider that keeps returning `ToolUse` is stopped at the cap with a verdict naming it; the window type exposes `append` and `rewind` and nothing that inserts or removes in the middle; the fake server's `Stall` script (keep-alives only, no event) is interrupted by `hand:kill` within five seconds and the hand thread ends, proven by a test that fails on the current code; the L1-10 done-check keeps every name, with one assertion re-pointed by design — `native_hand_tool_call_executes_once_and_makes_no_second_request` pinned the single call and now asserts the second request carries the tool result and no third is made; `L1-10`'s `Provider` trait, `Chunk`, `Termination` and `Message` are byte-identical.

## Shipped

The loop lives in `native_hand.rs` as `run_brief`, replacing `run_one_turn`: a `Window` seeded from the brief, `provider.complete(system, window.as_slice(), tools)` in a `1..=spec.steps` loop, each step's stream folded into one assistant `Message` and appended; `ToolUse` executes every call in order through the existing gate-and-dispatch code and appends one `Role::Tool` message per result before looping again; any other termination ends the brief with the last step's assistant text (the mechanical fallbacks kept verbatim) and the last step's usage. Reaching the cap with `ToolUse` still pending returns `native hand stopped at the step cap (<n> steps)` without executing that step's tool calls.

`Window` sits beside `Message` in `provider.rs`: `new`, `append`, `rewind` (truncate to a length, hand back the cut tail), `as_slice`, `len` — no insert, remove or splice. `rewind` lands with two unit tests and no caller in this card, as decided. `steps: Option<u32>` is additive on `RoleConfig`/`RoleRow`/`HandSpec`, defaulting to 16 (`DEFAULT_STEPS`), `0` refused at config resolution with `<agent>.steps must be positive`.

The kill path is live. `Cancel = Arc<AtomicBool>` enters through `build_provider`'s new parameter; `OpenAiCompatible` stores it and `SseChunks` checks it before the first read and after every `read_line`, yielding one `Fatal("killed")` then ending. `spawn_native_hand` now spawns two threads: a watcher blocking on `control_rx.recv()` that turns `Control::Kill` into the flag and ends, dropping a stray `Control::Steer` (the ledger already refuses steer for a native hand mid-turn before one is ever sent, so this stays a safety net); and the hand thread, which checks the flag after every stream item and after every tool execution and sends no delivery when it fires — the ledger's own kill path already wrote the row and pushed `Delivery::Killed`. A keep-alive stall now ends within one line of a kill instead of riding the 60 s request timeout; that whole-request timeout is what still bounds a byte-silent stall, unchanged from L1-10. `AnthropicStub` takes and ignores the flag. `git diff ef38d43 -- crates/arx/src/provider.rs` shows only `Window`, `Cancel` and `build_provider`'s new parameter as additions — `Provider`, `Chunk`, `Termination`, `ProviderError`, `Message`, `ContentBlock` and `ToolDef` are byte-identical.
