# L2-12 — the judge: schema, clamp, family warning

## Deliverable

L1-11's dispatch completed: read-only clamp, no save verb, no third lifetime class; the return an arx-defined verdict schema filled through `codex exec --output-schema`, parsed by the driver with its own failure path because Codex does not check the schema (R02); a same-family-as-main check at dispatch that warns and never refuses.
