## Bottom line

Both seats converged on four things: the vector-first funnel puts the leg with the measured drop failure in the one position where a drop is final (S-SOL-1, S-RUNE-4); "keep the bounce" lands on in-force `df14a2bc`, which rejected the synchronous gate and whose replacement fold no longer exists (S-RUNE-1); the gate's two jobs — contradiction surfacing, which the data grants, and duplicate precision, which it denies — need separate mechanisms (S-SOL-5, S-RUNE-3, S-RUNE-10); and the four-field schema lifts the one rule the owner never corrected over to schema while leaving derivability, the one he did, as prose (S-SOL-7, S-RUNE-9). They did not converge on whether BM25-only clutter is a real defect (S-SOL-2 — rune contests it as a ranking-noise claim nobody has measured, and withdrew its own counter-statistic) or whether the surfacer's interruption cost is still live for arx once `df14a2bc` moved adjudication off the write path (S-SOL-6). Both seats call **rethink**: rune on S-RUNE-1, S-SOL-1, S-SOL-5, S-RUNE-9; sol on S-RUNE-1, S-SOL-1, S-SOL-5, S-SOL-7.
