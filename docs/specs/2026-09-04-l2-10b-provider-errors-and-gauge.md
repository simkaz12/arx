## Problem / Solution

`ProviderError` has one variant. A 429, a 503, a dropped connection and a 400 for a prompt that no longer fits all arrive as `Fatal(String)` and end the hand with the same failure verdict; nothing retries, nothing parses the overshoot, nothing tells the operator a window constant is wrong. The gauge is worse than absent: `transcript::occupancy` sums Anthropic's three field names, so every native hand on DeepSeek reports zero and its nudge can never fire. No window limit exists anywhere in config, so there is no denominator to gauge against.

This card lands the three classes and the wrapper that acts on them. `ProviderError` becomes `Transient { kind, retry_after }`, `Fatal { kind }` and `ContextWindowExceeded { overshoot }`. A `Retrying` provider wraps every built adapter: a `Transient` from `complete` is retried after the vendor's `retry-after` or a short doubling backoff, a bounded number of times, honouring the cancel flag while it waits; once a stream has been returned nothing is retried. The OpenAI-compatible adapter classifies before the first item: transport errors, 429 and 5xx are Transient, a 400 whose body names the context length is ContextWindowExceeded with the overshoot parsed from "maximum context length is X ... requested Y", the rest Fatal. On a miss the native hand's verdict names the overshoot, a `miss` event carrying the size lands in the transcript log, and the terminal says the window constant for that model may need updating. The occupancy reader learns OpenAI's field names, so a DeepSeek hand's nudge works. The definition gains `window: Option<u64>`, the operator's constant for the model it names, and every verdict row for a native hand carries occupancy and window side by side.

## Decisions locked

- `provider.rs`: `pub struct Overshoot { pub requested: u64, pub maximum: u64 }`; `#[non_exhaustive] pub enum ProviderError { Transient { kind: String, retry_after: Option<Duration> }, Fatal { kind: String }, ContextWindowExceeded { overshoot: Option<Overshoot> } }`; `Display` renders `transient (<kind>)`, `fatal: <kind>`, `context window exceeded (requested N, maximum M)` or `context window exceeded (size unknown)`. `Fatal(String)` becomes `Fatal { kind }` at every constructor and pattern (the runner lists the sites); the trait, `Chunk`, `Termination`, `Message`, `Window`, `Cancel` do not change.
- The wrapper: `pub struct Retrying<P: Provider> { inner: P, cancel: Cancel, attempts: u32 }` implementing `Provider`; `complete` calls `inner.complete`; on `Err(Transient { retry_after, .. })` it waits `retry_after` if given, else `500 ms × 2^(attempt-1)`, polling the cancel flag every 50 ms and returning `Fatal { kind: "killed" }` if it is set, then tries again, up to `RETRY_ATTEMPTS = 3` calls in total; the last `Transient` is returned as is. `Ok(stream)` is returned untouched: an error yielded by the stream after the first item is never retried by this wrapper. `build_provider` returns `Box::new(Retrying::new(adapter, cancel.clone()))` for every kind. Unit tests in `provider.rs`'s test module with a scripted inner provider that fails N times.
- OpenAI-compatible classification in `complete`, before the first item: a transport error → `Transient { kind: "transport", retry_after: None }`; status 429 → `Transient { kind: "429", retry_after: <Retry-After header in seconds, if present> }`; 500–599 → `Transient { kind: "<status>", retry_after: <header> }`; 400 whose body (as text) contains `context_length_exceeded` or `maximum context length` → `ContextWindowExceeded { overshoot: parse_overshoot(&body) }`; every other non-2xx → `Fatal { kind: "http <status>" }` with the redacted body tail as today. `pub fn parse_overshoot(body: &str) -> Option<Overshoot>` finds the first integer after `maximum context length is` as `maximum` and the first integer after `requested` (or `resulted in`) as `requested`, without a regex crate; either missing → `None`. Errors that a stream yields mid-way (malformed SSE, EOF) stay `Fatal` with today's texts.

## Chosen without a grill

- **A wrapper type, not retry logic inside each adapter.** `3a5aefb6` names the stream wrapper as the retrier; one type over the trait retries every adapter the same way and L2-10c gets it for free. Rejected: retry loops in `OpenAiCompatible::complete`.
- **Three attempts, 500 ms doubling, header first.** A bounded, vendor-informed wait is what the ruling asks for; the numbers are the smallest that survive a single 429 burst. Rejected: unbounded retries; a configurable policy (nothing to size it against yet).
- **Classification by status and body text, no vendor table.** The two strings the ruling quotes are the OpenAI wire's own; DeepSeek and OpenRouter pass them through. Rejected: per-vendor error catalogues.
- **`miss` on the delivery, the event emitted by main.** Only main writes the transcript log; the same shape `walls` took in L2-08. Rejected: the hand thread writing events.
- **`window` on the definition, not on the provider row.** `aca8f7ef` says per-model; a definition names exactly one model, and the provider row serves many. Rejected: a `[providers.<name>.models]` table.
- **Occupancy by field presence, Anthropic first.** The nudge's existing tests pin the Anthropic sum; OpenAI's `prompt_tokens` already includes cached tokens on the vendors seen. Rejected: summing `prompt_cache_hit_tokens` and `prompt_cache_miss_tokens` (DeepSeek-only names).
- **No live miss.** A real 400 needs a prompt past a real window; the hermetic fake server proves the classification and the parse, and a short live brief proves no regression on the happy path. Rejected: a live overflow brief that would spend the owner's key on a rejected request.
