# L3-01 — admission

Card: `docs/wayfinder/maps/arx-v0/L3-01-admission.md`. Ruled by D03 (`bb4099ad` admission makes no store call in either direction, a handle is a filesystem path the ordinary read tool pulls; `0bec7b13` traces land under the session that produced them, write-once, the preview is the head plus path, byte and line count, a handle pull is not exempt and arx tracks no set of externalized paths; `3d559805` the session-scoped result cache keyed on the exact call with a sha check, anything without a sha re-runs; `32809bf6` one default of 1,000 tokens plus a per-tool override table that ships empty; `1fa2bae0` no tool-pair splice, the externalize write falls back from the session dir to `/tmp` and fails the call only when both fail), D07 (`e65b2a35` two tiers, inline or externalize-plus-handle, the preview is a truncated head and the round trip is the model's), D11 (`2248d3ac` the cache holds externalized results only; `21f24656` a whole-body pull of a sealed trace mints nothing and an over-threshold slice externalizes ordinarily with its own sha; `8098d8ee` the same-handle return is an echo on its own counter, not a pull, with one mechanical line and no recommendation), D16 (`70260cad` admission covers mounted tools, which under a Claude Code main is the whole surface), `40ebd8d3` the memory seam is exempt, `0aa87641` memory defers rather than overrides, `d5e60f47` the harness never moves its own constants. No grill: the owner ruled the overnight chain runs on main's own recommendation where a grill would have stopped it (2026-09-04). Every call main made alone is under "Chosen without a grill".

## Problem / Solution

Nothing judges a tool result before it enters a window. Main's `read_file` cuts at 16 KiB and appends a line telling main to dispatch a hand for the rest, so a 100 KiB file is unreachable past its head and the cut sits in the window at full price. The native hand's `read_file` returns whole files with no bound at all. Neither tool takes a range, so even with a handle the model would have no way to slice. The `admission`, `pull` and `echo` event shapes have existed since L2-01 with no live emitter.

After this card, every non-exempt tool result on main's surface and inside the native loop passes one function. Under the threshold it enters whole and writes an `admission` row with outcome `inline`. Over it, the body is written entire as a write-once `.md` under the thread with frontmatter naming its source, sha, producer and time, and the window gets the head plus the handle, byte and line counts. `read_file` gains `offset` and `limit`, so the model pulls the part it needs; a slice is a `pull`, a whole read of a sealed trace over the threshold is an `echo` that returns the same handle and mints nothing. A repeat of an externalized call whose source sha is unchanged gets the first handle back. Store results never pass admission. The threshold is one config constant with a per-tool override table that ships empty; the harness surfaces counts and the owner moves the table.

## Decisions locked

- Two outcomes: inline at or under the threshold, externalize over it. The estimate is the crate's bytes-over-four. The default threshold is 1,000 tokens; `[admission] threshold_tokens` overrides it, `[admission.overrides]` maps a tool name to its own threshold and ships empty. Nothing in arx changes these at runtime.
- Exempt by seam, not by name: results of `save`, `recall`, `decisions_query`, `decision` and `drain` on main, and `recall` on a native hand, enter whole and write no admission row.
- A trace is a `.md` file under a directory directly under `threads/`: `threads/<thread>.traces/<turn>-<n>.md` for main, `threads/<thread>.<hand>.traces/<step>-<n>.md` for a native hand. Written once with `create_new`, never reopened. Frontmatter: `producer: externalized tool result`, `tool`, `source` (the path, `path#L<a>-L<b>` for a slice, the tool name when there is no path), `sha256` of the source file at capture or the literal `none: always recheck`, `thread`, `turn` (or `step`), `captured_at` unix seconds, `bytes` and `lines` of the body. The body follows the closing `---` verbatim.
- The preview is one mechanical line plus the head. Externalized: `[arx] externalized <tool> result: <handle> (<bytes> bytes, <lines> lines; body from line <k>)` then the first 1,024 bytes of the body cut at a char boundary. Echo: `[arx] this result is the whole of <handle>; the handle is unchanged (<bytes> bytes, <lines> lines)` then the first 1,024 bytes of the file. Cached: the first run's preview byte for byte. No wording recommends a slice; `prompts/main.md` teaches the slice.
- Trace root test: a read is trace-rooted when its canonical path sits inside a directory directly under the thread root (`threads/<something>/…`). Top-level files in `threads/` (the transcript logs, checkpoints, native hand `.jsonl` traces) are not traces and read ordinarily.
- Echo: trace-rooted, no range, body over the threshold. Returns the echo preview, writes `Event::Echo { handle }`, no admission row, no file, no cache entry. Pull: trace-rooted and material admitted (an inline whole or slice, or an externalized slice) — writes `Event::Pull { handle: <the trace file's path>, path: <the request as given, with #L range when ranged> }` beside the admission row.
- Cache: session-scoped map from `(tool, canonical args JSON)` to `(handle, source sha, preview)`, populated only on externalize, consulted only over the threshold. The read runs (that is how the sha is known); a match returns the stored preview with `admission` outcome `cached` and the same handle; a mismatch externalizes afresh and replaces the entry. Results with no source sha are never entered.
- Write failure: the trace dir under `threads/` first, then `std::env::temp_dir()/arx-traces/<thread>/`; the handle is whichever path was written; both failing fails the tool call with the error text. Main's `read_file` accepts the fallback root as a second permitted root so the handle always resolves.
- `read_file` on both surfaces takes optional `offset` (1-based line, default 1) and `limit` (line count, default to the end). The 16 KiB cap and its line are removed; admission replaces them.
- Native pulls are served by the loop from the host directory, never through the container: a `read_file` path beginning with the hand's handle prefix (`/hand/traces/` under a container host, the host directory under a local host) strips the prefix, refuses anything but a bare file name, and reads `threads/<thread>.<hand>.traces/<name>` on the host. No new mount, no change to the exec script.
- Admission rows for a native hand go into the hand's own trace as the serialized `Event`, so the shape is L2-01's; main's rows go through `TranscriptLog::append_event`.
- Hand verbs and `edit_file` pass through the same function for their row; when one externalizes, the result value is `{"text": <preview>}` and the sidecar renders `text` when present.
- Outcome strings: `inline`, `externalized`, `cached`.

## Execution plan

### Scope 1 — `admission.rs`: the policy, the estimate, the trace writer, the cache

- **Files:** Create `crates/arx/src/admission.rs`; Modify `crates/arx/src/main.rs` (`mod admission;` beside the other module lines), `crates/arx/Cargo.toml` only if `sha2` is not already a dependency (L3-03 added it)
- **Build:** one module with no knowledge of sidecars or providers.
- **Steps:**
  1. `pub struct AdmissionPolicy { pub threshold_tokens: u64, pub overrides: BTreeMap<String, u64> }` with `Default` = 1000 and empty; `pub fn threshold_for(&self, tool: &str) -> u64`. `pub fn tokens(bytes: usize) -> u64 { (bytes as u64).div_ceil(4) }` — the same arithmetic as `provider::estimate_tokens` (`provider.rs:79-91`); do not change that function. `pub const PREVIEW_HEAD_BYTES: usize = 1024`.
  2. `pub struct TraceRoot { pub host_dir: PathBuf, pub handle_prefix: String, pub fallback_dir: PathBuf }`. `handle_prefix` is what the model sees before the file name (`threads/main.traces` for main, `/hand/traces` for a container hand, the host dir for a local hand). `fallback_dir` is `std::env::temp_dir().join("arx-traces").join(thread)`.
  3. `pub struct Provenance { pub source: String, pub sha256: Option<String> }`. `pub fn sha256_hex(bytes: &[u8]) -> String` via `sha2`.
  4. `pub struct Cache` (`HashMap<String, CacheEntry { handle: String, sha256: String, preview: String }>`, key = `format!("{tool}\u{0}{}", canonical_args)` where canonical args is `serde_json::to_string` of the args Value with object keys sorted).
  5. `pub struct Request<'a> { pub tool: &'a str, pub args: &'a serde_json::Value, pub body: &'a str, pub provenance: Provenance, pub trace_rooted: Option<String>, pub ranged: bool, pub ordinal: u64 }` — `trace_rooted` carries the trace file's path when the read was under the trace root, `ordinal` is the turn (main) or step (hand).
  6. `pub struct Admitted { pub text: String, pub outcome: &'static str, pub handle: Option<String>, pub events: Vec<Event> }`.
  7. `pub fn admit(policy: &AdmissionPolicy, cache: &mut Cache, root: &TraceRoot, seq: &mut u64, req: Request) -> Result<Admitted, String>`, in this order: (a) `tokens(body.len()) <= threshold_for(tool)` → inline: text is the body, events `[Admission { outcome: "inline", bytes, handle: None }]` plus `Pull` when `trace_rooted`. (b) over the threshold and `trace_rooted.is_some() && !ranged` → echo: read the file's byte and line counts, text is the echo preview, events `[Echo { handle }]`, nothing written. (c) over the threshold, cache hit with equal sha → text is the stored preview, events `[Admission { outcome: "cached", bytes, handle: Some }]` plus `Pull` when trace-rooted. (d) otherwise externalize: `*seq += 1`, file name `<ordinal>-<seq>.md`, write with `OpenOptions::new().create_new(true)` into `host_dir` (creating it), on any error retry once under `fallback_dir`, on a second error return `Err(format!("{tool} error: could not externalize the result: {err}"))`; frontmatter per Decisions locked; preview per Decisions locked with `body from line <k>` where k is the frontmatter's line count plus one; insert into the cache only when `provenance.sha256` is `Some`; events `[Admission { outcome: "externalized", bytes, handle: Some }]` plus `Pull` when trace-rooted. `handle` is `format!("{}/{}", root.handle_prefix, name)` for the host dir and the absolute path for the fallback dir.
  8. `pub fn is_trace_rooted(threads_dir: &Path, canonical: &Path) -> bool`: `canonical` strips `threads_dir` and the remainder has at least two components. `pub fn slice_lines(text: &str, offset: Option<u64>, limit: Option<u64>) -> Result<String, String>` — 1-based `offset`, refuses `offset` of 0 or past the last line with `read_file error: offset <n> is past the last line (<total>)`; keeps line endings.
  9. Inline `#[cfg(test)]` tests in `admission.rs` (the file is not `#[path]`-included anywhere; do not include it from any test binary): `threshold_for_falls_back_to_the_default`, `tokens_is_bytes_over_four_rounded_up`, `an_inline_result_writes_one_row_and_no_file`, `an_externalized_result_is_write_once_with_frontmatter_and_a_head` (asserts every frontmatter key, the `create_new` name never reused across two calls, the preview line), `a_cache_hit_returns_the_first_preview_and_a_sha_change_misses`, `a_whole_read_of_a_trace_over_the_threshold_is_an_echo`, `externalize_falls_back_to_tmp_when_the_session_dir_refuses` (make `host_dir` a regular file; assert the handle is under `fallback_dir`), `slice_lines_is_one_based_and_refuses_a_past_the_end_offset`.
- **Verify:** `cargo test -p arx --bin arx admission::` → 8 passed.
