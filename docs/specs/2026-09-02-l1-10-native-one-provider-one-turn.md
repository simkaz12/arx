# L1-10 — native: the provider trait, one adapter, one turn

Card: `docs/wayfinder/maps/arx-v0/L1-10-native-one-provider-one-turn.md`. Ruled by D02 (`975f65cd`, `48af6ac7`, with `72bfc6e9` and `bd73693e` as the in-force companions on chunk shape and assembly), D07 (`7dae481c`, `e65b2a35`), T01 (`docs/wayfinder/maps/arx-design/findings/T01-findings.md`), `af68d429` (the ratification that restates `6bbde714`), D14's `7e2202a7`, D06's `96d1ad3a`, D16's `0bd4df2f` — if a step below lands against one of those, stop and report; do not bend the step or the ruling.

## Problem / Solution

L1-08 and L1-09 put two CLI bodies behind the dispatch seam. The native slot is still dead: `resolve_hand_spec` returns `body 'native' not implemented until L1-10` (`main.rs:227`) and the ledger arm is `unimplemented!` (`ledger.rs:355`). Config already parses `body: native` plus a `provider` name and refuses a native role without one, but nothing consumes the name. There is no HTTP client, no message type, no tool-call type and no tool executor anywhere in the workspace.

This brief fills the slot at layer-1 width: the stateless provider trait, one OpenAI-compatible adapter that takes a `base_url`, a second adapter stub that compiles against the trait, a `[providers]` table in config so a definition's `provider` resolves to bench configuration, and a loop that completes exactly one turn in the hand role — one request, its stream, its tool calls executed through the gate seam, results appended, no second request. Fatal surfaces as a failure verdict. The retry wrapper, the other error classes, the window gauge, rewind, the Anthropic adapter's body and multi-turn are L2-10.

## Decisions locked

- Trait shape is the ruling's, verbatim in Rust: `fn complete(&self, system: &str, messages: &[Message], tools: &[ToolDef]) -> Result<ChunkStream, ProviderError>` on `pub trait Provider: Send + Sync`. Takes `&self`, holds no session state, carries no `name()`, no capability method, nothing the loop can branch on (`975f65cd`; T01 §5's `manages_own_context()` shape stays rejected). The model id is fixed at construction — provider selection is spawn-time composition named by the agent definition, so the adapter is built once per dispatch from `(kind, base_url, api_key, model)`.
- The stream is a synchronous iterator, `Box<dyn Iterator<Item = Result<Chunk, ProviderError>> + Send>`. arx's crate is std threads and mpsc throughout (`spawn_claude_hand`, `spawn_codex_hand`); the lift from Goose is the trait's semantics, not its async runtime. HTTP goes through `reqwest::blocking`; tokio appears in no arx-authored code.
- Chunks are semantic, assembled inside the adapter (`72bfc6e9`): `Chunk::Content(ContentBlock)` for a text fragment or one complete tool call, `Chunk::Terminal { termination, usage }` once per stream. The loop reads content blocks and assembles the assistant `Message`; wire deltas, block indexes and `[DONE]` never cross the seam.
- Termination is the four-value enum `EndTurn | ToolUse | MaxTokens | Refusal { category }` (`48af6ac7`). The OpenAI-compatible adapter translates `finish_reason`: `stop` → EndTurn, `tool_calls` → ToolUse, `length` → MaxTokens unconditionally (`7e2202a7`), `content_filter` → Refusal{"content_filter"}, any other value (DeepSeek documents `insufficient_system_resource`) → Refusal with the raw value as category. A `stop` on a response that assembled tool calls is ToolUse — the adapter owns that vendor quirk, the loop never re-derives termination from content.
- `ProviderError` has one variant at this layer, `Fatal(String)`. Every non-2xx status, transport failure, malformed SSE data line, or stream ending without a `finish_reason` is Fatal. L2-10 adds the other classes and the retry wrapper; the enum is `#[non_exhaustive]` so it can.
- Request assembly is identity (`bd73693e`): system prompt first, then the window as-is, then the tool surface. The native hand's window at spawn is `[User(brief)]` — a fresh composition, not a projection of main's. Grounding push into the window is L2-05; the system prompt is the shared `ARX_HAND_INSTRUCTIONS` constant, made `pub(crate)` in `codex_hand.rs` and imported, not copied.
- The hand's tool surface is one built-in, `read_file { path }`, executed on the host relative to `spec.cwd` and confined to it. It exists so the trait's `tools` parameter and the loop's execute-and-append phase are real at this layer; a wider surface and the engine's `recall` tool (`e79bed85`) are later cards. Every tool call crosses `Gate::decide` before it executes (`96d1ad3a`, same seam as main's), with `AllowAll` behind it until L2-02; the crossing is a row in the hand's trace. Deny becomes the tool result text; Ask is treated as deny with a note that ask routing for native hands lands at L2-11.
- Tool results are appended whole. The admission ladder (`e65b2a35`, inline vs externalize-plus-handle) is implemented at L3-01; no cap, no truncation, no filter here — a third mechanism would be new design.
- One turn means one `complete` call. When the termination is ToolUse the loop executes each call in order and appends each result as a `Tool` message, then stops. The verdict is the assistant text when there is any; when there is none and tool calls ran, a mechanical line naming the count; when the termination is Refusal with no text, a mechanical line naming the category. A fatal is the failure verdict `native hand failed — <error>` and still lands.
- The trace is arx-written, `threads/<thread>.<hand>.jsonl`, one JSON row per event (request, assistant, gate, tool_result, termination, error). `TranscriptLog` is not reused: its thread-name charset rejects `.`, and widening it is not this card. The trace handle shape matches L1-08/09.
- Config gains a `[providers.<name>]` table with exactly three keys — `kind` (`openai-compatible` | `anthropic`), `base_url`, `api_key_env` — and a native role's `provider` must name a row (`0bd4df2f`: body, model, provider are the three fields; the vendor's endpoint is bench config, `975f65cd`). OpenRouter or any other OpenAI-shaped vendor is another row with `kind = "openai-compatible"`, never a third adapter.
- The API key is read from the named env var at dispatch time and never stored on `HandSpec`, in a ledger row, in the trace, or in any request field other than the `Authorization` header. A missing or empty variable refuses the dispatch before spawn with an error naming the variable, the same pre-spawn refusal shape as the reserved `judge` name.
- Kill on a native hand drops the stream: the SSE reader checks `control_rx` after every line (comments and blanks included), and again before delivering; a Kill or a disconnected channel at any point means no verdict is sent. Steer is refused mechanically with a `refused: true` ledger row, extending the L1-09 branch to `Native` with the label `native`. The refusal text keeps the shape the tests already match: `{hand} is a native hand mid-turn; steer is not deliverable — kill and re-dispatch`.
- Usage is whatever the vendor's final chunk carries (`stream_options.include_usage`), recorded verbatim on the verdict ledger row, absent from main's window line — the L1-09 rule.
- The loop module names no adapter type. The only place concrete adapters are spelled is the factory in `provider.rs`; `native_hand.rs` holds a `Box<dyn Provider>` and nothing else. This is the card's third done-when and is checked by grep.
- The second adapter is `AnthropicStub` in `crates/arx/src/anthropic.rs`: implements `Provider`, returns `Fatal("anthropic adapter lands at L2-10")` from `complete`, and is what `kind = "anthropic"` resolves to. L2-10 fills the body without touching the trait.

Each event's JSON (`serde_json::Value`, unknown fields ignored) is folded into state: `choices[0].delta.content` (string, non-empty) → yield `Content(Text)`; `choices[0].delta.tool_calls[]` fragments assembled by `index` into `{id, name, arguments: String}`; `choices[0].finish_reason` non-null → remembered; top-level `usage` non-null → remembered. When `finish_reason` arrives, or on `[DONE]`/EOF with fragments pending, each assembled tool call is yielded as `Content(ToolCall)` with `arguments` parsed as JSON, falling back to `Value::String(raw)` when it is not JSON (the executor's validation reports it; it is not a Fatal). On `[DONE]` or EOF: a remembered `finish_reason` → yield exactly one `Terminal` with the mapping from Decisions locked; none → `Err(Fatal("stream ended without finish_reason"))`. A `data:` payload that is not JSON → `Err(Fatal("malformed SSE data: <line tail>"))`. After the first `Err` or the `Terminal`, the iterator returns `None` forever. Expose a `pub(crate) fn chunks_from_reader(r: impl BufRead + Send + 'static) -> ChunkStream` so unit tests feed canned bytes.
